# Adaptive UTE v2：明日模拟测试说明

## 测试目的

验证新的决策层是否比单纯顺着 UTE 信号更稳。UTE 内核保持不变，策略同时观察 UTE 原始五因子和现有结构指标，选择：

- **UTE_TREND_CONTINUATION**：证据、量能、方向效率支持延续，且 5m/15m 没有有效反向冲突时，顺 UTE 方向入场。
- **UTE_REVERSAL_FADE_LONG / UTE_REVERSAL_FADE_SHORT**：UTE 分数可以很高，但必须同时满足信号成熟度与至少两项反转线索，才逆 UTE 方向做反转试探。
- 证据不足时不交易。没有固定的“深夜禁交易”时间条件；相对量能按最近 3 根均量除以前 10 根均量计算并参与判断。

## 初始规则（用于实验，不是回测结论）

### 顺势延续

- UTE score >= 55。
- UTE directionalConsistency >= 0.55。
- 方向 ER >= 0.30。
- UTE volumeRatio >= 0.65，且低周期/高周期没有有效反向冲突。
- UTE 方向、原始突破和结构突破没有互相打架；假突破出现时不追入。

### 反转试探

- UTE score >= 60；不能仅凭“score >= 70”直接反做。
- 成熟度要求：confirmCount >= 4；或 score >= 75、strength >= 0.75 且 directionalConsistency >= 0.75。
- 至少两项反转线索，并至少一项来自主证据：
  - 对抗 UTE 方向的长影线；
  - UTE 或结构指标出现反向突破；
  - 假突破；
  - 5m 或 15m 有效方向与 UTE 相反。
- 次级线索包括相对量能衰减（volumeRatio < 0.75）、ER 走低、区间扩张或极端波动。
- 相对量能低于 0.35 时两种模式都不入场；反转模式风险预算乘以 0.65。

### 离场

- 顺势仓：价格逆行 1.15% 止损；保证金浮盈达到 26% 后，峰值回吐 14% 时移动止盈。
- 反转试探仓：价格逆行 0.85% 止损；保证金浮盈达到 18% 后，峰值回吐 9% 时移动止盈。
- 反转仓不会仅因其来源 UTE 周期 ENDED 或原方向仍与仓位相反就立刻平掉；仍由策略止损/移动止盈和后续新反向周期管理。非反转模式继续沿用基础设施原有的 ENDED/反向确认退出。
- 每个 UTE 周期最多开一笔，避免同周期反复试错。

## 明日操作与记录

1. 在部署/预览环境使用 `algorithm-optimization` 分支，算法下拉选择 **自适应 UTE 趋势/反转（adaptive-ute-v2）**。
2. 首轮建议 `reverseMode=OFF`，先测这套新算法自己选择的方向。若要研究全局反向执行，再用独立测试时段单独打开 `reverseMode=ON`；两组不要混在同一收益结论里。
3. 切换前先保存目前报告。若重置模拟账户，会清除旧交易记录；只有确认已保存后再重置。
4. 每次复盘至少记录：strategy/modeTag、score、confirmCount、returnPct、directionalConsistency、volumeRatio、breakout、rangeExpansion、ER、falseBreakout、影线、5m/15m 方向、持仓分钟数、退出原因、净盈亏和是否强平。
5. 分开看顺势模式与反转模式的交易数、净盈亏、PF、平均单笔、最大回撤、连续亏损和强平数。另按 volumeRatio 分组，判断是否真的存在相对量能较低时表现恶化；不要只按新加坡时间段下结论。

## 解释边界

UTE score 是启发式证据分，不是胜率概率。当前阈值是便于模拟比较的初始工程参数；短时间、少量交易或单一行情 regime 不能证明算法具备稳定优势。全局 reverseMode 还会让执行方向反转但保留模型侧策略决策与退出时机，强平也不对称，因此它适合作为单独对照组，而不是把每笔盈亏简单乘以 -1。
